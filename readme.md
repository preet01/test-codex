# Snake II

A modernized take on the classic Snake II arcade game. Guide the neon serpent, chase glowing bites, and survive an increasingly fast maze.

## Play locally

Open `index.html` in any modern browser—no build step required. For a quick local server you can also run:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

### Controls
- Arrow keys or **WASD** to turn (or tap the on-screen arrows on touch devices).
- **Space** to pause/resume.
- **Enter** or the **Restart** button to reset when you crash.

### Notes
- Speed ramps automatically as your score increases; the speed readout shows your current multiplier.
- Your best score is stored in the browser so you can keep climbing the leaderboard.
- The overlay is clickable for quick restarts on desktop and mobile.
