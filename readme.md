# Snake II

A modernized take on the classic Snake II arcade game. Steer a neon snake to eat dots, grow longer, and avoid crashing into walls or your own tail.

## Play locally

Open `index.html` in any modern browser—no build step required.

### Controls
- Arrow keys or **WASD** to turn.
- **Space** to start or pause the run.
- **Enter** or the **Reset run** button to restart when you crash.
- Touch-friendly D-pad buttons for mobile.

### Notes
- The board is a fixed grid; hitting the edges or your tail ends the run.
- Your best score is stored in the browser so you can keep climbing the leaderboard.
- Speed ramps up every few snacks—keep calm and steer clean lines.
