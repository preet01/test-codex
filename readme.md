# Jaipur Exploration Planner

A single-page website that helps you turn your must-see Jaipur spots into a smooth day plan. Use filters (vibe and time of day), search, and quick-add cards to build an ordered loop that limits backtracking.

## Run locally
Open `index.html` in any modern browser or serve the folder (e.g., `python -m http.server 8000`) and visit `http://localhost:8000`.
